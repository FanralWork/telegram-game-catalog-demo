# Каталог игр в Telegram

Учебный бот показывает демонстрационный каталог игр и корзину. Кнопки добавляют позиции, а команда `/basket` выводит список и сумму. Корзина хранится в памяти отдельно для каждого чата.

## Установка

Требуется Python 3.11 или новее. Выполните команды из папки проекта в PowerShell.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Настройка и запуск

Имена параметров перечислены в `.env.example`. Программа читает окружение. Укажите собственные значения в текущем сеансе PowerShell.

```powershell
$env:TELEGRAM_BOT_TOKEN='<ваше значение>'
.\.venv\Scripts\python.exe main.py
```

В Telegram откройте `/games`, добавьте позицию через кнопку и выполните `/basket`. Цены используются как демонстрационные данные. Оформление заказов и платежи отсутствуют.

Рабочие ключи, базы и файлы состояния предназначены для локального хранения. Проверяйте подключение в собственном тестовом чате или канале.
